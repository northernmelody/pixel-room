## 交互原则

- 人物、猫和狗按北京时间及各自状态机自主活动。
- 正式页面没有移动、楼层切换或“开始任务”按钮，点击空地不改变任何角色目标。
- 点击人物只播一段短横版姿势（wave/nod/startle/lookback，1.2–1.8 秒）并短暂停住移动，不改变作息档案、目的地和计时；睡眠与淋浴中不回应。点击猫、狗按横版语义产生短时互动状态（见下节），同样不动作息与膳食计时。
- 点击回应不再使用文字气泡：人物用横版姿势动画，猫用抬头／蹭手／翻肚皮／伸爪分级姿态，狗用吠叫张嘴上绘制。原横版由点击触发的跟狗、连续摸猫走开、弹吉他和换衣，现在既保留自主版本，也重新提供横版那样的人工点击入口。
- 页面内不再提供设置入口与横版入口：声音开关留在「☰ 小屋菜单」，设置页与横版由直接链接进入。

## 新增庭院秋千

秋千位于前院左侧，使用木质 A 字支架、双绳和单人木座板。人物在休闲时自主打开院门、走到秋千、摆动并在活动结束后继续下一项生活。21:00 后及雨、雪、雷雨天气不新安排秋千活动。秋千是纯场景道具：横版没有对应入口，因此它不可点击、也没有悬浮标签。

草坪上另有两件像素玩偶：秋千左侧的大象与秋千、踏石之间的长颈鹿（`GARDEN_TOYS`，程序化绘制、随昼夜调色，带落地阴影）。它们是纯场景装饰，同样不可点击、无悬浮标签；契约测试断言两者都在草坪内、且不与秋千支架、两段踏石和四条花坛重叠。

## 横版可操作交互的竖版对应（2026-09-17 收束完成）

基准是 `../handoff.md` 的「横版点击交互清单」：竖版只保留横版已有的可操作交互，装饰物件不再打开详情弹窗。

| 横版交互 | 竖版入口 | 拒绝条件与提示 |
| --- | --- | --- |
| 小人：短暂回应 | 点击人物 → 横版姿势（挥手／点头／惊醒／回头）+ 提示音 | 睡眠与淋浴中不回应；不改作息、路线与计时 |
| 猫：摸猫、连摸后走开 | 点击猫 → 抬头叫 → 蹭手（爱心）→ 翻肚皮 → 第 4 次伸爪走开；高处先落地、床下先出来 | 睡眠中只回应不移动 |
| 狗：首点吠叫，短时间再点跟随 | 点击狗 → 张嘴吠叫 2 秒；4 秒内再点 → 跟随 10 秒 | 无 |
| 吉他：取琴、弹唱、归还 | 点击木吉他 → `startGuitar()` | 正在弹唱 `busy`、睡着 `sleep`、通话 `call`、洗漱或淋浴 `wash` 时给文字提示 |
| 电脑：打开放大屏、换台 | 点击书桌 → 六频道弹窗，换台/遮罩/按钮关闭 | 无 |
| 六盏灯：点击开关 | 点击灯珠 → 开关并重绘 | 5 秒内累计 3 次 → 猫躲进床底、人物抬头、提示一次，30 秒冷却 |
| 玩偶与腊肠狗抱枕：名称提示 | 点击 6 个墙面玩偶或床 → 「🧸 名称」提示（墙面第 4 个在竖版改为哈密瓜切片，提示为「MOMO的黄瓜」） | 无 |
| 两封信：阅读正文 | 点击书架 → 两封信入口 → 正文弹窗 | 无 |
| 餐食热点：显示当前食物 | 点击吊柜/台面/餐桌 → 当前菜名或零食名 | 没有做饭时提示「餐桌是空的」 |
| 衣柜：开门查看（2026-09-17 改） | 点击衣柜 → 门向两侧打开，内部显示随机像素颜色衣物；再点或在 5 秒后自动关上 | 不再触发换衣；换衣只保留为晚间自主行为 |
| 冰箱：开门查看（2026-09-17 新增） | 点击冰箱 → 门向右打开，内部显示随机像素颜色食物；再点或 5 秒后自动关上 | 无 |
| 户外木门：未开放提示 | 点击木门 → 提示门还锁着 | 无 |
| 通话期间 MOMO 卡片：完整记录 | 通话时段左下角出现卡片，点击 → 100 天通话正文 | 非通话时段卡片隐藏 |

实现方式：`js/layout.js` 的物件带 `action` 字段作为唯一白名单（16 个物件），`js/scene.js` 的 `hitTest()` 只返回带 `action` 的物件，`js/main.js` 按 `action` 分派到弹窗、提示或开门状态。因此“是否可点”由数据决定，新增装饰物件默认不可点。`js/scene.js` 的 `propContents(kind, seed)` 生成衣柜／冰箱内容，`PROP_BOX` 限定它们的可见区域。

角色姿势由 `js/art/generate.mjs` 从横版 `drawReact`／猫狗渲染函数生成，同一角色的所有变体共用联合包围盒与锚点（`ITEM_META.anchorX/anchorY`），因此切换姿势不会让脚底跳动。淋浴使用新增的仅内裤形象，并由 `drawFrontProps()` 在人物前方绘制关闭的玻璃门与水流。

证据：`node portrait/tools/browser-check.cjs`（真实 Chromium，见 `artifacts/browser-check.log`）逐项点击验证上述行为，并确认地毯、窗户、冰箱、狗粮碗、马桶、挂钟与秋千点击后既无弹窗也无提示。

## 独立验证任务重点

验证入口：`npm --prefix portrait test`（语法 + 契约 + 横版保护哈希）、`python portrait/tools/serve.py` 后运行 `node portrait/tools/browser-check.cjs`（真实 Chromium 点击回归，需要 Chrome 与本地服务）。

1. 用测试时间覆盖所有作息边界、夜间事件、三餐和晚间通话，使用 `?d=YYYY-MM-DD&t=HH:MM:SS` 固定日期与时刻。
2. 验证每种动作的站位、遮挡、持物和收尾，尤其是楼梯、衣柜、淋浴、吉他与秋千。
