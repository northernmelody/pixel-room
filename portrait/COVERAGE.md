# 竖版功能覆盖清单

状态：2026-09-17。核心自主运行、边界和交互已通过静态契约与真实浏览器验证；“已实现”与“已通过”仍分开记录，未完成的视觉等价项列在文末。

点击范围已于 2026-09-17 按横版可操作清单收束：只有横版本来就有的入口可点，装饰家具、窗户、地毯、摆件与秋千既无弹窗也无悬浮标签。对应表见「横版可操作交互的竖版对应」。

本轮时间线改造（2026-09-17）：`life.js` 现在按上海/北京时间的日期生成确定性的星期档案。工作日共享晨间、午间和工作骨架，晚间按周一至周日分别进入恢复、运动、兴趣、轻休闲、周末前、自由日和收束日档案；换衣只出现在晨间，睡前包含 `undress` 语义，秋千可在早餐后的晨间缓冲段发生。时间线不再从单一晚间随机池抽取活动。

## 交互原则

- 人物、猫和狗按北京时间及各自状态机自主活动。
- 正式页面没有移动、楼层切换或“开始任务”按钮，点击空地不改变任何角色目标。
- 点击人物只增加短时回应层，不停止移动、不重置活动计时、不改变目的地；点击猫、狗、吉他和衣柜按横版语义产生短时互动状态（见下节），但不改动作息档案与膳食、通话等计时。
- 原横版由点击触发的跟狗、连续摸猫走开、弹吉他和换衣，现在既保留自主版本，也重新提供横版那样的人工点击入口。

## 新增庭院秋千

秋千位于前院左侧，使用木质 A 字支架、双绳和单人木座板。人物在休闲时自主打开院门、走到秋千、摆动并在活动结束后继续下一项生活。21:00 后及雨、雪、雷雨天气不新安排秋千活动。秋千是纯场景道具：横版没有对应入口，因此它不可点击、也没有悬浮标签。

## 横版可操作交互的竖版对应（2026-09-17 收束完成）

基准是 `../handoff.md` 的「横版点击交互清单」：竖版只保留横版已有的可操作交互，装饰物件不再打开详情弹窗。

| 横版交互 | 竖版入口 | 拒绝条件与提示 |
| --- | --- | --- |
| 小人：短暂回应 | 点击人物 → 画布回应气泡 + 提示音 | 不改作息、路线与计时 |
| 猫：摸猫、连摸后走开 | 点击猫 → 抬头叫 → 蹭手 → 翻肚皮 → 第 4 次伸爪走开；高处先落地、床下先出来 | 睡眠中只回应不移动 |
| 狗：首点吠叫，短时间再点跟随 | 点击狗 → 吠叫 2 秒；4 秒内再点 → 跟随 10 秒 | 无 |
| 吉他：取琴、弹唱、归还 | 点击木吉他 → `startGuitar()` | 正在弹唱 `busy`、睡着 `sleep`、通话 `call` 时给文字提示 |
| 电脑：打开放大屏、换台 | 点击书桌 → 六频道弹窗，换台/遮罩/按钮关闭 | 无 |
| 六盏灯：点击开关 | 点击灯珠 → 开关并重绘 | 5 秒内累计 3 次 → 猫躲进床底、人物抬头、提示一次，30 秒冷却 |
| 玩偶与腊肠狗抱枕：名称提示 | 点击 6 个墙面玩偶或床 → 「🧸 名称」提示 | 无 |
| 两封信：阅读正文 | 点击书架 → 两封信入口 → 正文弹窗 | 无 |
| 餐食热点：显示当前食物 | 点击吊柜/台面/餐桌 → 当前菜名或零食名 | 没有做饭时提示「餐桌是空的」 |
| 衣柜：晚间休闲换衣 | 点击衣柜 → `startChange()` | 只在晚间休闲档案内换衣，其他时间提示稍后再来 |
| 户外木门：未开放提示 | 点击木门 → 提示门还锁着 | 无 |
| 通话期间 MOMO 卡片：完整记录 | 通话时段左下角出现卡片，点击 → 100 天通话正文 | 非通话时段卡片隐藏 |

实现方式：`js/layout.js` 的物件带 `action` 字段作为唯一白名单（15 个物件），`js/scene.js` 的 `hitTest()` 只返回带 `action` 的物件，`js/main.js` 按 `action` 分派到弹窗或提示。因此“是否可点”由数据决定，新增装饰物件默认不可点。`inventory()`、「今天的生活」汇总、秋千弹窗和全物件悬浮标签已删除。

证据：`node portrait/tools/browser-check.cjs`（真实 Chromium，见 `artifacts/browser-check.log`）逐项点击验证上述行为，并确认地毯、窗户、冰箱、狗粮碗、马桶、挂钟与秋千点击后既无弹窗也无提示。

## 独立验证任务重点

1. 用测试时间覆盖所有作息边界、夜间事件、三餐和晚间通话，使用 `?d=YYYY-MM-DD&t=HH:MM:SS` 固定日期与时刻。
2. 验证每种动作的站位、遮挡、持物和收尾，尤其是楼梯、衣柜、淋浴、吉他与秋千。
3. 在人物、猫、狗移动和动作中连续点击，确认作息、路线与计时没有被改写，且猫摸链、狗跟随、闪灯惊吓都按横版语义收敛。
4. 检查猫狗跨层、高处、床下、粮碗消耗以及刷新后的世界进度。
5. 检查 6 个电脑频道、100 天通话索引、上传信件、三首歌词及七夕指定日期。
6. 回归点击范围：装饰物件与秋千保持无命中无提示，15 个可操作物件的入口不被误改动；改动物件 `action` 时同步更新契约测试的期望集合。
7. 检查天气 API 成功／失败、自动灯光、声音开关、跨日快递与收藏。
8. 检查桌面及 320×568、375×812、390×844、430×932，修复控制区撤下后的布局和热点问题。
9. 保持契约测试与真实浏览器验证并行；旧 S3/S4.1 针对手动控制的断言应替换为自主行为断言。
