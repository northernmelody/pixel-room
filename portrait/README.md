## 正式交互

- 页面打开后自动按北京时间进入当前生活阶段，没有移动按钮或任务启动按钮。
- 点击空地不控制人物；方向键也不负责移动。
- 点击人物、猫、狗显示当下回应并播放已启用的提示音，自主路径、状态和计时保持不变。
- 点击家具查看物件；点击电脑进入六频道放大画面；点击书架读取两封信；“今天的生活”可查看当晚通话和信件。
- 六盏灯可以点击，也可以在设置页控制；默认按昼夜和安静时段自动开关。
- 声音默认关闭，用户主动开启后才创建 WebAudio 上下文。

## 自主生活

人物包含睡眠、晨间如厕／冲水／洗手／刷牙、三餐、工作与喝水、晚间休闲、21:30 通话、22:00 淋浴、夜间如厕／喝水／夜宵／手机活动。晚间休闲包括游戏、阅读、运动、逗猫、看窗、手机、零食、换衣、完整弹唱和庭院秋千。

猫包含漫游、理毛、睡眠、狂奔、蹭人、攀爬与高处停留、抓窗帘、床下、进食和逗猫联动。狗包含漫游、睡眠、进食、狂奔、自主跟随、吠叫、抓挠和坐下。两只宠物使用与人物相同的楼梯导航图，但各自拥有状态和速度。

庭院新增木质 A 字秋千。天气和时段合适时，人物会自己经过院门走到秋千；点击秋千只显示介绍。

- 保留 53 个原绘制对象、4 个房间、4 扇窗、6 盏灯、7 个玩偶。

- 跨日补充宠物粮，推进快递和五类收藏；竖版世界与横版存档隔离。

## 信件上传

`/setting` 为两封信各提供一个文件槽，支持 TXT、Markdown 和 JSON。文件在浏览器本地读取并存入 `pixel-room-portrait-letters-v1`，不会发送至服务器。Markdown 首行 `# 标题` 可以覆盖信件标题；JSON 支持 `title`、`from`、`to`、`paragraphs` 或 `body`。每个文件限制 100 KB，可以一键恢复内置信件。

## 主要模块

| 模块 | 职责 |
| --- | --- |
| `js/time.js` | 北京时间、`?t=` 测试时间和日期编号 |

| `js/pets.js` | 猫狗自主状态、跨层导航、进食与独立点击反馈 |
| `js/environment.js` | 北京天气请求、超时和离线兜底 |
| `js/audio.js` | 用户启用后的 WebAudio 反馈、动作和环境提示音 |
| `js/store.js` | 设置、动态物品、快递收藏、跨日和存档隔离 |
| `js/letters.js` | 两封信上传解析、覆盖和恢复 |
| `js/navigation.js` | 三层楼梯、院门与庭院路径 |
| `js/scene.js` | 房屋、家具、动态角色、秋千、动作道具、天气和光照 |
| `js/main.js` | 页面装配、内容弹窗、电脑、通话、物件和主循环 |
