## 正式交互

页面打开后自动按北京时间进入当前生活阶段，没有移动按钮或任务启动按钮；点击空地不控制人物。点击范围与横版一致，`js/layout.js` 的物件 `action` 字段是唯一白名单。画面左上角的说明条显示「季节 · 光照 · 当前行为」（例如「秋日 · 阳光正好 · 走到电脑前」），右侧是北京时间；窄屏下行为文字省略，时间不会被挤掉。

- 人物：横版姿势回应（挥手／点头／惊醒／回头，约 1.2–1.8 秒）与提示音，不改作息、路线和计时；睡眠与淋浴中不回应。
- 猫：摸猫链——3 秒内连点到第 4 次会伸爪走开；高处先落地、床下先出来。狗：首次点击吠叫，4 秒内再点跟随 10 秒。
- 吉他：点击取琴弹唱并逐句显示歌词；正在弹唱、睡着、通话、洗漱或淋浴时给出文字提示。
- 电脑：点击书桌打开六频道放大画面，可换台、点遮罩或关闭按钮退出。
- 衣柜与冰箱：点击打开柜门／冰箱门，内部显示随机像素颜色的衣物／食物，再点一次或 5 秒后自动关上；衣柜不再触发换衣。
- 六盏灯：点击开关，也可以在设置页控制；5 秒内连闪 3 次会把猫吓进床底（30 秒冷却）。
- 玩偶与腊肠狗抱枕：点击显示名称提示。书架：两封信的正文。吊柜／台面／餐桌：当前食物，没做饭时提示餐桌是空的。户外木门：显示未开放提示。
- 通话：晚间通话时段左下角出现 MOMO 卡片，点击阅读完整记录。
- 装饰家具、窗户、地毯、摆件、家电、粮碗、快递箱与秋千：不可点击、无悬浮标签、不弹窗。
- 声音默认开启，首次点击或按键后创建音频上下文；开关保留在「☰ 小屋菜单」。页内不再放置设置与横版入口，直接访问 `/setting` 与 `/classic`。

## 自主生活

人物包含睡眠、晨间如厕／冲水／洗手／刷牙、三餐、工作与喝水、晚间休闲、晚间通话、淋浴、夜间如厕／喝水／夜宵／手机活动。晚间休闲包括游戏、阅读、运动、逗猫、看窗、手机、零食、换衣、完整弹唱和庭院秋千；具体顺序由当天星期档案决定。淋浴时淋浴间玻璃门关闭，人物以仅内裤形象站在水流后方。

猫包含漫游、理毛、睡眠、狂奔、蹭人、攀爬与高处停留、抓窗帘、床下、进食和逗猫联动。狗包含漫游、睡眠、进食、狂奔、自主跟随、吠叫、抓挠和坐下。两只宠物使用与人物相同的楼梯导航图，但各自拥有状态和速度。

庭院新增木质 A 字秋千。天气和时段合适时，人物会自己经过院门走到秋千；秋千本身是不可点击的场景道具。

## 信件上传

`/setting` 为两封信各提供一个文件槽，支持 TXT、Markdown 和 JSON。文件在浏览器本地读取并存入 `pixel-room-portrait-letters-v1`，不会发送至服务器。Markdown 首行 `# 标题` 可以覆盖信件标题；JSON 支持 `title`、`from`、`to`、`paragraphs` 或 `body`。每个文件限制 100 KB，可以一键恢复内置信件。

## 主要模块

| 模块 | 职责 |
| --- | --- |
| `js/time.js` | 北京时间、`?t=` 时刻与 `?d=` 日期测试入口、日期编号 |
| `js/life.js` | 星期档案、自主作息、动作序列、休闲、夜间、餐食、歌曲、手动弹唱/换衣入口与回应 |
| `js/pets.js` | 猫狗自主状态、跨层导航、进食、摸猫链、狗叫/跟随与受惊躲藏 |
| `js/environment.js` | 北京天气请求、超时和离线兜底 |
| `js/audio.js` | 用户启用后的 WebAudio 反馈、动作和环境提示音 |
| `js/store.js` | 设置、动态物品、快递收藏、跨日和存档隔离 |
| `js/letters.js` | 两封信上传解析、覆盖和恢复 |
| `js/navigation.js` | 三层楼梯、院门与庭院路径 |
| `js/layout.js` | 物件、房间锚点、六盏灯与可操作白名单（`action`） |
| `js/scene.js` | 房屋、家具、动态角色与姿势变体、秋千、动作道具、衣柜/冰箱开门内容、天气、光照与点击命中 |
| `js/art/generate.mjs` | 从横版绘制函数生成竖版精灵：人物姿势、仅内裤淋浴形象、猫摸链分级、狗吠叫 |
| `js/main.js` | 页面装配、点击分派、开门状态、内容弹窗、电脑、通话卡片和主循环 |

## 已执行检查

```powershell
npm --prefix portrait run check
npm --prefix portrait test
python portrait/tools/serve.py          # 另开一个终端
node portrait/tools/browser-check.cjs   # 真实 Chromium 点击与内容回归
node portrait/tools/viewport-check.cjs  # 真实视口回归（320/375/390/430/1440）
```

`check` 执行模块语法检查；`test` 还会运行自主行为与点击范围契约、以及原版保护检查。`browser-check.cjs` 通过 CDP 驱动本机 Chrome，把 `tests/browser.html?autorun` 的真实点击结果写入 `artifacts/browser-check.log` 并截图；`viewport-check.cjs` 用 CDP 视口仿真（Chrome 在 Windows 下会忽略 `--window-size` 的页面布局，必须用仿真）逐档断言说明条、时钟与画布都在画面内且页面无横向溢出，加 `--shots` 时输出 `_shots/viewport-<w>x<h>.png`。两者都需要 Chrome 与 `serve.py` 同时可用。原版受保护文件没有在本轮修改。旧版横向 smoke 中仍有三项坐标/接口断言失败，详见 [功能覆盖清单](COVERAGE.md)，不计入竖版契约结果。
